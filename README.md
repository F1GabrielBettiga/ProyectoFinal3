Catálogo Web de Productos – ASP.NET | Proyecto Final C# Nivel 3
📌 Descripción

Aplicación web desarrollada como Proyecto Final del Curso C# Nivel 3 de Maxi Programa, dictado por el profesor Maximiliano Sar Fernández.

El sistema está orientado a un comercio o emprendimiento que necesita mostrar su catálogo de productos de forma online, permitiendo a los usuarios navegar los artículos disponibles y a los administradores gestionar el contenido desde un área protegida por login.

🚀 Funcionalidades principales
🏠 Portal público

Pantalla Inicio con catálogo de productos en formato tarjetas

Filtros por categoría, marca y rango de precios

Pantalla de detalle del producto

Navegación simple y orientada a la experiencia de usuario

🔐 Área de administración

Login con control de acceso por rol

Listado de artículos

Búsqueda por distintos criterios

Alta, modificación y eliminación de productos

⭐ Funcionalidades adicionales

Registro de usuarios

Gestión de perfil

Sistema de favoritos por usuario

🛠️ Tecnologías utilizadas

C#

ASP.NET WebForms

Arquitectura en capas (Dominio, Negocio y Datos)

SQL Server

HTML5

CSS3

Bootstrap

Hosting y base de datos en SOMEe.com

📐 Arquitectura

La aplicación fue desarrollada siguiendo una arquitectura en capas, separando responsabilidades para lograr un sistema más mantenible y escalable:

Dominio: modelos de negocio

Negocio: lógica y validaciones

Datos: acceso a base de datos

Presentación: interfaz web

🗄️ Base de datos

Base de datos SQL Server

Persistencia completa de productos, marcas, categorías, usuarios y favoritos

Script de creación de base de datos incluido en el repositorio

🌍 Deploy

La aplicación fue desplegada en un entorno real utilizando hosting y base de datos remotos, enfrentando escenarios reales de publicación y configuración.
